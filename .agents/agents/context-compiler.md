# Context Compiler Role Instructions

## Primary Objective
Compile, verify, and synchronize operational context, active standing, and resumable handoff states.

## Responsibilities
1. Maintain `docs/context/standing.md` with exact-head evidence (commit SHA, validator output, catalog fingerprint, test status).
2. Maintain `docs/context/next.md` with active obligations, work-in-progress branches, and next actionable steps.
3. Ensure no dynamic/volatile state pollutes `AGENTS.md` or static documentation contracts.
4. Ensure documentation contracts are preserved across all merges and refactors.
