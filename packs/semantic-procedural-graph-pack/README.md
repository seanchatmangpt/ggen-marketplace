# semantic-procedural-graph-pack

Reusable SPG vocabulary and admission shapes.

The pack deliberately does **not** define a new planner, process log, theorem prover, or authority system. It supplies one semantic identity that can be projected to specialized machinery such as HDDL, FOND, TLA+, OCEL 2.0, SA2A and BRCE.

## Core law

```text
candidate != truth != capability != authority != DO != standing
SELECT(Gn) != CONSTRUCT(DeltaG) != ADMIT(Gn + DeltaG) != DO
```

A consequential edge is structurally inadmissible unless it names a non-NONE authority requirement, requires a receipt, and carries a falsifier.

SPG structural admission remains powerless. Actual consequence stays behind BRCE.

## Prior art

Every graph contains at least one `spg:PriorArtClaim`. Novelty is represented by the prior-art admission pack and cannot be inferred from unfamiliarity.

## Falsifier

The pack is insufficient if a required procedural semantic property materially affects lawful observable execution and cannot be represented or explicitly bounded as unsupported.
