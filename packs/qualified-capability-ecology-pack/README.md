# Qualified Capability Ecology

Canonical lifecycle:

```
DISCOVER/CLASSIFY
      |
      v
CANDIDATE -- independent court + replay --> QUALIFIED
      |                                      |
      |                                      v
      |                                  FROZEN CLOSURE
      |                                      |
      |                                      v
      |                                  RUNTIME EPISODE
      |                                      |
      |                                      v
      +----------------------------- OBSERVATION RECEIPT
                                             |
                                             v
                                     EVOLUTION PROPOSAL
                                      (authority = none)
                                             |
                                             v
                                         REQUALIFY
                                             |
                                             v
                    consequence-preserving SUBSTITUTION
                                             |
                                             v
                   negative residual-human-work delta
                                             |
                                             v
                                           RETIRE
```

A candidate is not truth, qualification is not DO authority, and a generated
projection is not standing. Every consequential action remains external to
this pack and must pass BRCE.

The retirement gate counts exception, verification, correction and
maintenance work. Replacing the common case while increasing residual human
work is therefore a refusal, not an automation success.
