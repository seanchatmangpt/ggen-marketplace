# Explanation: realization is topology evidence

Expected option capital is not realized option capital. R22 made the opportunity hypergraph explicit; R24 made qualified realization explicit. Their composition creates a feedback law: observations update confidence in an edge without erasing the edge or granting execution authority.

This is intentionally not a single optimizer. Conservative yield protects downside, optimistic yield preserves exploration, reuse-adjusted yield values reusable manufacture, and failed-edge queries retain missing primitives as adjacency information. The Pareto query collapses only strict domination among reversible edges.

Calibration is therefore a SELECT-side epistemic operation. It changes which options have standing for further construction; it does not perform consequential actuation. A future BRCE boundary may consume a calibrated candidate, but this pack cannot manufacture DO authority.
