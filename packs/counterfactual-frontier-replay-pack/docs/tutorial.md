# Tutorial: manufacture a replayable frontier

Model several qualified candidates in `ontology.ttl`, run the two ggen rules, and inspect the projected frontier and replay court. The pack keeps SELECT/CONSTRUCT/VERIFY authority separate from DO and preserves non-dominated alternatives rather than collapsing to one winner. Re-run generation from identical ontology/query/template inputs and compare outputs byte-for-byte before treating the projection as replayable evidence.
