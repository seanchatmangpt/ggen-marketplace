# How to extend the option frontier

Add candidate facts with reversibility, expected reuse, expected capability-space delta, exact current standing, receipt digest, and non-DO authority. Add pairwise or higher-order `cfr:Composition` facts instead of overwriting earlier candidates. Extend ranking queries only when the new objective is independently falsifiable; keep Pareto preservation and replay gates intact. Validate the marketplace, run this pack's tests, then qualify generation against the matching ggen runtime and a real consumer boundary.
