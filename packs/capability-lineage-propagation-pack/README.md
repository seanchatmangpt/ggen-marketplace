# Capability lineage propagation factory

This pack manufactures a propagation **plan**, never consequential actuation. It exists for the recurring case where an exact-qualified capability must move through a proven Git ancestry after intermediate PR wrappers have already closed.

Law: qualified source -> immutable ancestry proof -> zero semantic delta propagation edges -> non-force construction plan -> exact target qualification -> containment receipt.

A propagation edge may preserve an already-qualified capability but must not be counted as new semantic manufacture. Diverged ancestry, unknown source standing, force-ref mutation, ambient DO, or semantic drift typed-refuse. Generated propagation plans remain consequences rather than editing surfaces.
