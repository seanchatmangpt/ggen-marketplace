# DfCM Deterministic Dynamic UI Pack

This pack makes deterministic dynamic UI a generated consequence of admitted RDF rather than an authored source of organizational truth.

`UI_t = P(G_t, avatar, context, authority, grammar)`

The ontology fixes the constitutional boundary: presentation SELECT remains reversible, CONSTRUCT requires explicit admission, and consequential DO requires BRCE receipt standing. Rendering never confers actuation authority and `irreversibleSelections = 0` for presentation composition.

## Manufacture

`ggen.toml` consumes `ontology.ttl`, executes `queries/contract.rq`, and renders `templates/DDUI_CONTRACT.md.tmpl`. The generated reference therefore derives SELECT/CONSTRUCT/DO constraints from the admitted graph instead of duplicating them manually.

## Falsifiers

The pack is invalid if its generated reference permits irreversible UI selection, render-to-DO authority escalation, CONSTRUCT without explicit admission, DO without a receipt boundary, or an intent whose actuation flag is true.
