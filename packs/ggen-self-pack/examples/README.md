# ggen-self-pack/examples

Real, runnable examples of `ggen-self-pack` consuming its own vocabulary --
not prose describing what the pack could do. Each example should be a
small, self-contained `.ttl` fact file (or a pair: facts + the generated
output it produces) that a reader can point `ggen sync` at directly to
see real rendered output, the same way this pack's own
`qualification/project/input.ttl` proves `ggen pack new` end to end.

Generated by `ggen pack new ggen-self-pack` from `ggen-self-pack`. Populate
this directory as the pack's real capabilities are built -- an empty
`examples/` with only this README is a lawful starting state, not a
finished one; a pack whose only example is prose is not yet demonstrated.
