# How to add an exploration edge

1. Add a reversible `cloc:CompositionEdge` with source/target capability, posterior, expected delta/reuse, cost, latency, and uncertainty.
2. If construction cannot proceed, record `cloc:missingPrimitive`; do not delete the edge.
3. Bind current realized evidence to an exact subject and 64-character receipt digest with ALIVE or PARTIAL_ALIVE standing.
4. Run all gates and policy queries.
5. Regenerate the portfolio and qualification court deterministically.
6. Treat outputs as SELECT/CONSTRUCT evidence only; any DO transition requires a separate BRCE path and receipt.
