# Explanation: exploration as a lawful feedback controller

Realized qualification changes the topology worth exploring, but it must not silently become an execution policy. This pack therefore treats calibration as observation, policy scoring as SELECT, deterministic generation as CONSTRUCT, and consequential actuation as a separate BRCE-only transition.

Multiple policies coexist because each preserves a different form of option capital: uncertainty keeps learning edges alive, reuse rewards generalized manufacture, cost and latency expose economic surfaces, missing-primitive queries turn failure into graph structure, and Pareto filtering removes only strict domination. The result is a feedback controller for exploration, not a winner-take-all optimizer.
