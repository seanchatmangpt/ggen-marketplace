# Multi-cell consumer factory

This pack manufactures a bounded consumer from two or more compatible marketplace cells without collapsing their standing or authority. Source hierarchy is `ontology.ttl -> SPARQL frontier -> ggen projection -> generated manifest/court -> exact consumer qualification`.

The reference composition is deliberately four-cell: documentation, consequence IR, evidentiary standing, and DfCM option court. Each cell remains independently qualified; SELECT and CONSTRUCT do not grant consequential DO. Generated files are consequences, never editing surfaces.

A lawful consumer must pin its repository/SHA subject, pin pack/ggen identities, preserve at least one reversible alternative where a selection court is used, prove deterministic regeneration, verify receipts, and qualify the generated consequence on its own exact subject.
