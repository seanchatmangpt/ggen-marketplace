# Falsifiers

Lower or refuse standing if any of the following is observed:

- an earned-release projection contains a claim with no exact-subject execution receipt;
- a source article or model summary is treated as authority or ALIVE evidence;
- the same admitted graph and template identities render materially different outputs;
- a consumer hand-edits a generated release/acceptance artifact instead of repairing ontology/template source;
- a target repository is created or published without its owning authority boundary;
- the working-backwards release is published as if already earned.
