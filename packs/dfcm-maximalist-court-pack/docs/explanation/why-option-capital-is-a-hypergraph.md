# Why option capital is a hypergraph

A task list collapses composition structure: it records isolated work items but not the higher-order relationships that make new software possible after a merge, ontology admission, pack addition, or runtime interface appears. R12 therefore models opportunities as nodes, lawful combinations as composition hyperedges, and executable candidates as manufactured consequences.

This preserves reversible alternatives until evidence establishes domination. Pairwise success does not imply higher-order success; pairwise failure does not refute unrelated edges. Marketplace support and public ontologies are themselves reusable capital because one admitted semantic primitive can unlock many consumer candidates. The result is a queryable frontier whose growth can be measured by executable-candidate yield, reuse, reversibility, capability-space delta, and newly unlocked adjacency while preserving SELECT != CONSTRUCT != DO.
