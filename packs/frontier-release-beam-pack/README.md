# frontier-release-beam-pack

Companion pack for `beam4pm-process-model-pack`. It contributes four `bpm:RecordType` families to the merged graph:

- `frontier_source_release`
- `frontier_opportunity`
- `frontier_benchmark`
- `frontier_evidence`

The existing beam4pm process-model templates then manufacture the language/schema projections. This pack defines **no** `bpma:AdmittedActuation` individuals: observation, opportunity selection, benchmark representation, and evidence carriage do not grant repository-creation, deployment, publication, communication, or spending authority.

Consumer qualification requires a real ggen regeneration against the pinned process-model pack and must prove the new records compile/test across the consumer's existing projection ladder. Pack presence alone is not execution standing.
