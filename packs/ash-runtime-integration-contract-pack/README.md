# Ash Runtime Integration Contract Pack

Deterministic GGen source for generating Ash/Reactor runtime seams from admitted RDF facts. The pack binds exact subjects, authority, runtime actions, receipts, replay, refusals, OCEL evidence, persistence, API/CLI surfaces, and failure semantics without granting model or planner output ambient execution authority.

The pack is source-only. Consumer projections belong in consumer repositories. Process-intelligence algorithms remain outside this pack and are consumed through wasm4pm/wasm4pm-compat interfaces.
