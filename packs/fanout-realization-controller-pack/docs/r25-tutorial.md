# Tutorial: measure a fanout control decision after selection

1. Materialize the exact `ControlDecision` subject and receipt identity.
2. Record the selected `ControlOutcome`; never infer it from the decision.
3. Record independently observed alternatives only when they actually executed.
4. Run the R25 courts for prediction error, dependency relief, cost/latency, currentness, evidence-root duplication, and observed-only regret.
5. Admit positive standing only from current receipted outcomes; an unobserved alternative remains missing evidence.
6. Regenerate the bounded report/court with ggen; generated outputs are consequences, not editing surfaces.

The tutorial preserves `SELECT != CONSTRUCT != DO`; R25 authority is `OBSERVE|VERIFY` and consequential actuation remains BRCE-only.
