# Explanation: why recombination changes frontier topology

Enumeration only counts already-visible choices. Recombination introduces reusable morphisms among capabilities, ontologies, packs, repositories, consumers, runtimes, falsifiers, and verifiers. Those morphisms let later runs derive candidate families that did not exist as explicit nodes beforehand. The pack therefore treats option capital as a hypergraph expansion problem while preserving SELECT/CONSTRUCT/DO separation and reversible non-dominated alternatives.
