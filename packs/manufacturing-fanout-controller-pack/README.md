# Manufacturing fanout controller

This pack composes qualified marketplace factories into a bounded fanout plan. It does not actuate consumers. It selects which reusable asset should serve which consumer and whether the downstream path is direct generation or lineage propagation.

Capital law: `Y = expected future qualified consumer actions / current investment units`. Only positive-Y edges enter the default frontier; realized Y remains a downstream evidence obligation.

The controller requires exact subjects, qualified factories, independent consumer qualification, preserved alternatives, deterministic projections, and no ambient DO. Generated fanout plans are consequences, never editing surfaces.
