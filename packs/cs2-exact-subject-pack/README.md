# CS2 Exact Subject Pack

Reusable semantic manufacturing substrate for RFC-CS2-001. The pack projects one canonical source identity into consumer bindings and executable-witness descriptors without copying an implementation.

## Contract

A projection is useful only when it binds the exact CS2 subject, canonical repository, exact source commit, source digest, consumer commit, and (for executable witnesses) witness path + digest.

The template is the generated-source input. Consumers provide data; they do not hand-edit the projection vocabulary. SPARQL gates describe refusal surfaces for divergent subject identity, floating source identity, and witness-free claims.

This pack grants no actuation authority.
