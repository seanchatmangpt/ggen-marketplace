# How to qualify a consumer realization candidate

1. Bind the candidate to an exact repository/ref or SHA.
2. Keep the candidate reversible until selection evidence dominates alternatives.
3. Choose at least one verifier and one dependency-relief strategy.
4. Run all ten ASK gates; any false gate refuses admission.
5. Run the permanent Python courts with `python3 -m unittest discover -s packs/consumer-realization-frontier-pack/tests -p 'test_*.py' -v`.
6. Manufacture deterministic projections from `ggen.toml`.
7. Independently execute the chosen consumer boundary before promoting its standing to ALIVE.
8. Record source identity, validator identity, execution evidence, receipt identity, and replay path. Structural cardinality alone never upgrades consumer standing.
