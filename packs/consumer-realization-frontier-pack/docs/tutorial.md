# Tutorial: expand an independent consumer frontier

Start with an exact repository subject already admitted as evidence. Add it as a `crf:RepositoryTarget` with `crf:independentConsumer true`, then choose reversible realization surfaces, verifier strategies, dependency-relief mechanisms, receipt strategies, and resilience strategies. Run the ggen rules to project consumer-bound plans. Treat the resulting cross-product as option capital, not actuation authority: SELECT ranks and preserves alternatives, CONSTRUCT may render plans, and DO remains fenced behind BRCE.

The seed model demonstrates 1,125 structural five-axis plans per consumer. That count is a deterministic property of the admitted model and is deliberately not evidence that 1,125 plans executed successfully.
