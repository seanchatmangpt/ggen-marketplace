# How-to — diagnose a stalled capital ready set

If a high-value candidate is not selected, inspect legality before score. Query admissible-but-not-ready work, hard-gate failures, authority coverage, exact-subject identity, downstream customer/shape, predecessor edges, broker coverage, and receipt requirements. Do not serialize compatible work merely to simplify scheduling. Repair shared defects upstream in ontology/pack/generator source, regenerate consumers, requalify exact heads, and recompute the ready set.
