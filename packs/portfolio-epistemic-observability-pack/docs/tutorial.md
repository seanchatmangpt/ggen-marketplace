# Tutorial: manufacture a portfolio observation frontier

Model exact repositories, heads, observations, capabilities, sensor runs, opportunities, and receipts in RDF using PROV-O, DCAT, DQV, SKOS, ODRL, and DCTERMS. Run the census and drift queries first, then materialize the clean-current frontier through ggen. Generated files are consequences; edit ontology, queries, templates, fixtures, and gates instead. Treat lexical GitHub searches as partial evidence and record the observation method so coverage and concentration are measurable rather than assumed.
