# How-to — diagnose a falling repository-manufacturing rate

Run the exact census first, then evaluate sensors 31–38. A falling `commitsPerHour` is a constraint observation, not permission to weaken meaning. Correlate the drop with unresolved heads, missing structural observations, missing GGEN paths, qualification backlog, fanout gap, and unattributed commits. Repair the highest causal constraint and preserve the new detector so the class remains observable.

Never classify temporal-neighbor commits as run-attributed without an exact Schedule-Run trailer or ledger binding.
