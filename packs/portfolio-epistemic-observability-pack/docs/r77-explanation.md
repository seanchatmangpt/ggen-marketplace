# Explanation — why exact repository-universe observability changes the factory

A bounded repository-count estimate cannot support portfolio-wide G, D, F, U, E, M, OCEL density, or RevOps claims. R77 converts the repository population into a timestamped exact-subject graph so every later structural observation can attach to a repository/default-branch/head identity and can be invalidated when that identity changes.

This changes the production function: one read-only census feeds structural displacement discovery, marketplace pack selection, consumer fanout, qualification, throughput attribution, agent-learning promotion, OCEL relations, and economic evidence. The census is therefore upstream epistemic capital rather than a report.

The public-semantic model reuses PROV-O, DCAT, DQV, DCTERMS, and ODRL. The local vocabulary names only domain-specific manufacturing measurements. GGEN owns deterministic frontier projection; generated artifacts remain consequences.
