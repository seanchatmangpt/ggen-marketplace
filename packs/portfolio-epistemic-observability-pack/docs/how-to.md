# How to roll out portfolio sensors

For each reachable repository, resolve the default branch to an exact SHA and append a repository observation with method, timestamp, provenance root, and standing. Add capabilities only when supported by source or execution evidence. Run all sensors against the accumulated graph; convert each actionable result into an Opportunity linked by PROV generation edges. Never infer fleet-wide coverage from a lexical commit search alone. Consequential changes remain outside this pack and must enter BRCE with their own receipt.
