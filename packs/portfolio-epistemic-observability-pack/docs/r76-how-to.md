# How-to — diagnose a throughput constraint

Bind commits to an exact schedule run before counting them. Separate meaningful semantic commits from control and merge commits. Compare current rate with prior-hour and prior-same-cell evidence only when those rates are independently observed. If rate falls while actionable structural displacement remains, treat the delta as a constraint observation. Inspect G, consumer fanout, upstream-learning realization, and OCEL density to locate the multiplier before manufacturing the next intervention.
