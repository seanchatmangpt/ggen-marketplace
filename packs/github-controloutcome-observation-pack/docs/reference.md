# Reference

Status vocabulary: UNKNOWN, PARTIAL_ALIVE, ALIVE, BLOCKED, BUILD_BROKEN, UNSUPPORTED, and typed REFUSED.

Required observation identity: repository, 40-hex head SHA, current flag, authority, actuation flag, and 64-hex receipt digest. Runs add run id/attempt/workflow/conclusion. Jobs add job id/name/conclusion/duration/evidence root. Pull requests add PR number/base SHA/mergeability. Missing exact identity, current evidence, receipt, or observation-only authority is refused rather than guessed.

The query family is intentionally plural: correspondence, deduplication, independent roots, discovery multiplier, latency, common-cause pressure, Wilson inputs, Laplace inputs, and refusal frontier.
