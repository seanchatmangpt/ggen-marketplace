# Explanation: GitHub evidence is not authority

A successful workflow is an observation about one exact subject under one evidence root. It is not ambient execution authority and it is not independent merely because several jobs are green. This pack preserves the distinction by modeling run/job/PR evidence, evidence-root correlation, confidence alternatives, and typed refusals separately. The result is reversible option capital: downstream EXPLORE and SELECT cells can compare multiple calibrated views without manufacturing facts or collapsing failed edges.
