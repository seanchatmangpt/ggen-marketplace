## Generated surface

A consumer graph projects:

```text
RDF source
  ├─> generated/swe-prometheus-probe-manifest.json
  ├─> generated/swe-prometheus-mutation-manifest.json
  └─> generated/swe-prometheus-case.json
```

The first two are inputs to the autofde-lab execution/reconstruction courts.
The case JSON is downstream of paired evidence + scoring and is the VGG evaluator
input. None of these generated bytes owns authority.

## No dual bookkeeping

If the runtime contract changes, update this ontology/gates/templates and
regenerate. Do not patch a generated JSON manifest independently and then mirror
the change back into RDF later.
