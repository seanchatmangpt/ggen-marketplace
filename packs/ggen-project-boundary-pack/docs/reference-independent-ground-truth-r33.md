# R33 independent ground-truth calibration

Calibration evidence is admitted only when exact observations can be paired with independently rooted labels. Distinct names do not establish independence: source root, implementation, and model identity must differ before evidence can multiply confidence.

The reusable surface exposes confusion-matrix counts, precision, recall, F1, false-negative pressure, source diversity, and one current calibration generation. It carries OBSERVE|VERIFY|SELECT authority only and never consequential DO.
