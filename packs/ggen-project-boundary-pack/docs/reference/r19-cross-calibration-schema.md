# R19 cross-calibration reference

`CrossCalibratedComposition` links one composition candidate to one observability calibration. Required decision dimensions are reversibility score, confidence lower bound, expected capability-space delta, authority cost, qualification status, expected reuse, marketplace support, and frontier membership. Optional topology edges include dominance and missing primitive. Query files `r19-xcal-01` through `r19-xcal-12` are deterministic read-only projections.
