# R33 relief-weighted EXPLORE allocation

R33 allocates observation/manufacturing effort across a Pareto portfolio rather than selecting one winner. Candidate value combines dependency relief, information gain, reuse, composition value, and future manufacturing capacity while rollback and authority costs remain explicit.

The reusable query surface exposes relief, information and capacity densities; reuse/composition multiplication; risk-adjusted yield; a five-axis non-dominated frontier; and a high-Y frontier. The gate refuses nonpositive investment and any reported ambient actuation.

The reference fixture is a deterministic calibration portfolio, not a claim of realized fleet yield. SELECT remains reversible and does not imply CONSTRUCT or DO.
