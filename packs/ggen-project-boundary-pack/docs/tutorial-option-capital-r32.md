# Tutorial: realize an option-capital frontier

Start from admitted MEASURE evidence, not an unconstrained idea list. For R32 the source observation is the R31 post-merge ledger. Materialize each observed opportunity as a candidate record, attach its evidence root, repository, marketplace support, qualification surfaces, reversibility, expected reuse, and expected capability-space delta, then query the resulting RDF graph.

1. Load `option-capital-r32.ttl` and the R31 evidence root.
2. Run `queries/r32-01-live-candidates.rq` to enumerate realized candidates.
3. Run `queries/r32-02-compositions.rq` to enumerate lawful adjacency.
4. Apply the R32 gates before treating any candidate as admitted.
5. Use the fixtures to falsify domination, ordering sensitivity, stale evidence, and accidental DO authority.

The result is a reversible SELECT/CONSTRUCT artifact. It is not authority to actuate a consumer system.
