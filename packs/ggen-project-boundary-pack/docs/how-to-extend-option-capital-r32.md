# How to extend the R32 option-capital frontier

Add a candidate only when an observed capability or composition supports it. Record the full hyperedge in `option-capital-r32-ledger.jsonl`: capability, composition, candidate, repository, marketplace support, missing primitive, qualification, reversibility, expected reuse, expected capability-space delta, evidence root, and standing.

Preserve non-dominated alternatives. A failed composition edge changes topology; it does not invalidate adjacent candidates. Add a falsifier fixture for each new assumption and an RDF edge when the relationship belongs in the canonical graph. If a candidate needs consequential action, emit an intent for BRCE instead of actuating from EXPLORE.
