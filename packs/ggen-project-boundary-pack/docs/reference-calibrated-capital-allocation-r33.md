# R33 calibrated capital allocation loop

This composition turns the three R33 sibling assets into one reversible feedback loop: observed candidate realization supplies actual qualified-action yield; independently rooted ground truth bounds false-capital risk; relief-weighted allocation preserves a Pareto portfolio over dependency relief, information gain and future manufacturing capacity.

A decision is current only when realization, calibration and allocation identities are all present. Positive nominal yield is insufficient when false-capital risk is high or relief-adjusted value is negative. The clean frontier therefore requires positive calibrated yield, bounded false-capital risk, nonnegative relief value, exact correspondence and zero ambient actuation.

Reference fixtures are deterministic qualification evidence only. SELECT remains reversible; CONSTRUCT and consequential DO require separate authority and receipts.
