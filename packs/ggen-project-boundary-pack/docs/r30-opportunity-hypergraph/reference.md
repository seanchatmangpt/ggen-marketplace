# R30 opportunity-hypergraph reference

R30 defines six seed capabilities, twelve lawful compositions, eighteen executable candidate nodes, nine preserved frontier members, and thirty orthogonal SPARQL projections. The fixture includes pairwise and arity-3/4/6 compositions, existing/extended/new/missing marketplace-support states, qualification labels, reversibility, expected reuse, capability-space delta, and typed missing primitives.

`E2 = executable non-dominated candidates / actionable opportunities consumed`. The reference corpus records `E2 = 18 / 6 = 3.0`; this is fixture evidence, not an ecosystem-wide production claim.

Authority is `OBSERVE|VERIFY`. `SELECT != CONSTRUCT != DO`; consequential DO is not represented as an ambient candidate capability and remains BRCE-exclusive. The R30 authority ASK gate refuses any candidate with different authority or `actuationPerformed true`.
