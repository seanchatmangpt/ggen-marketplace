# How to use R29 in an hourly MEASURE cell

- Treat each sensor execution as a distinct exact-subject observation.
- Compute E, novelty, realization, precision/recall, cost-normalized yield, latency-normalized yield, and dependency relief.
- Escalate zero-novelty, high-E/low-closure, high-cost/low-yield, blind-spot, stale, split-current, authority-drift, and unreceipted runs into typed EXPLORE opportunities.
- Prefer sensors that create novel actionable dependency relief per unit cost over sensors that merely maximize finding count.
- Append realization/closure changes to the Innovation Capital Ledger after merges so stale OPEN opportunity state is detectable.
