# Why Better Eyes needs yield calibration

A sensor that finds many issues can still be poor epistemic capital: it may rediscover known work, miss grounded opportunities, produce findings that never become realizations, consume excessive observation cost, or create no dependency relief. R29 therefore separates discovery, novelty, realization, calibration, and relief.

The key law is `more observations != more epistemic capital`. Reusable sensing compounds only when it increases novel actionable reach while remaining current, receipted, authority-bounded, sufficiently precise/recallful, and economically useful. Saturated or blind sensors remain observable failure topology so EXPLORE can redesign them instead of silently accepting their output volume.
