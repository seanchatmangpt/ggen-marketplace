# R29 sensor-yield reference

R29 treats `E = actionable opportunities / seed observations` as a discovery-amplification metric, not a closure metric. It is evaluated alongside novelty rate, realization rate, false-positive and false-negative pressure, closure-adjusted E, cost-normalized yield, latency-normalized yield, dependency-relief rate, repository reach, saturation, currentness, receipt coverage, and authority integrity.

The bundled calibration corpus contains 12 seed observations and 12 actionable findings across three current sensors, so `E_reference = 1.0`. Five findings are realized and three relieve dependencies. Those reference values are fixture evidence only; they are not fleet-wide production claims.
