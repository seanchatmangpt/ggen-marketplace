# Why R27 exists

DfCM intentionally preserves reversible alternatives, but option count is not epistemic capital by itself. A locally richer option frontier may repeatedly inspect the same repository, reuse the same evidence root, rediscover duplicate opportunities, or produce findings that never relieve a dependency. R27 therefore treats reversible topology as a hypothesis whose portfolio-level observational value must be measured.

This changes the control objective from `maximize options` to `maximize lawful reversible options while measuring their realized observability contribution`. The critical negative cases are first-class: zero-yield options, option growth without repository reach, grounded missed opportunities, stale/split-current frontiers, sensor saturation, and actionable findings with zero realized relief.

The Innovation Capital Ledger makes the learning loop cumulative. Exact observations produce reusable sensors; sensors produce typed opportunities; opportunities can later produce remediation and dependency-relief evidence; receipts preserve subject, authority, consequence and replay. A later EXPLORE/SELECT cell can therefore prefer options with demonstrated epistemic ROI without deleting safe low-yield alternatives prematurely.
