# Tutorial: from reversible option growth to better eyes

R27 measures whether a newly admitted reversible option increases what the portfolio can observe. Start with exact seed observations, derive typed actionable opportunities, preserve their repository subjects and evidence roots, and run the R27 sensor family. A useful option should increase novel actionable discovery without hiding stale evidence, duplicate opportunities, missing receipts, or red dependency outcomes.

The core sequence is:

`option -> observation -> opportunity -> novelty -> dependency relief -> receipt -> replay`

Use `03-discovery-multiplier.rq` for E, `16-option-yield.rq` for opportunity yield per realized option, and `06-realized-dependency-relief.rq` to distinguish discovery from actual blocker discharge. Use the blind-spot and zero-yield sensors as falsifiers: an option portfolio can grow while observability remains flat.

R27 performs OBSERVE/VERIFY only. SELECT may consume its evidence later; CONSTRUCT and DO remain separate, and consequential actuation remains BRCE-only.
