# R33 live candidate realization control

R32 candidate existence is not realized manufacturing capital. R33 admits a candidate only after exact-subject observation binds qualified actions, positive investment, dependency relief, evidence roots, and current generation.

The production law is `candidate -> observed realization -> Y -> dependency relief -> evidence-root diversity -> current frontier`. `SELECT != CONSTRUCT != DO`; this surface carries OBSERVE|VERIFY|SELECT only and never grants consequential actuation.

Reference fixture values are calibration evidence, not fleet-wide productivity claims. A realization with zero qualified actions remains observable but cannot be promoted merely because it was selected upstream.
