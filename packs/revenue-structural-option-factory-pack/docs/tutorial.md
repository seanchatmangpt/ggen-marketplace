# Tutorial: manufacture a revenue option frontier

1. Admit the exact existing structure as evidence, not truth about the future.
2. Generate multiple reversible candidate structures.
3. Bind each candidate to a marketplace pack, falsifier, consumer, and qualification.
4. Project Ash, Reactor, OCEL, API, and value-evidence consequences deterministically.
5. Execute qualification in the consumer repository.
6. Promote only generalizable, provenance-bound learning upstream.
7. Regenerate compatible consumers and requalify them.

The loop optimizes accumulated manufacturing capability rather than one application implementation. Structural cardinality never proves realized revenue.
