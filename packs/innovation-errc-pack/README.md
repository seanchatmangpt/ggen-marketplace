# innovation-errc-pack

Executable, marketplace-first value-innovation selection for ggen.

## Purpose

This pack turns the ERRC grid (Eliminate, Reduce, Raise, Create) into deterministic manufacturing input instead of a slide or meeting artifact. The RDF graph carries the strategy facts, SPARQL gates fail closed on incomplete or over-authorized strategy surfaces, and ggen projects reviewable JSON and Markdown portfolios.

The pack has **SELECT authority only**. It does not merge, delete, publish, deploy, repin, or otherwise actuate. Downstream DO must remain behind the repository/runtime authority boundary and produce a receipt.

## Marketplace-first gym application

Use ERRC before consumer manufacture:

1. **Eliminate** duplicated consumer-local pack ownership only after marketplace equivalence and consumer standing are proved.
2. **Reduce** handwritten projections and direct path coupling where reusable packs can manufacture them.
3. **Raise** exact-SHA provenance, deterministic regeneration, independent consumer qualification, receipts, and replay.
4. **Create** shared gym-family composition frontiers from gym-specific packs plus generic OCEL, SHACL, standing, receipt/replay, and `multicell-consumer-factory-pack` capital.

This makes `ggen-marketplace` the reusable source of manufacturing knowledge while each gym remains the authority for its domain ontology, runtime boundary, and exact-subject qualification.

## Generation

From this pack directory with a compatible pinned ggen runtime:

```bash
ggen sync
```

Expected projections:

- `generated/innovation/errc-portfolio.json`
- `generated/innovation/ERRC.md`

Generated outputs are consequences, not marketplace source.

## Falsifiers

The strategy is not admitted if any ERRC quadrant has no proposal, if an ERRC strategy activity claims authority other than SELECT, or if the pack introduces local TBox/predicate vocabulary instead of public ontology predicates. Producer validation does not establish consumer standing.
