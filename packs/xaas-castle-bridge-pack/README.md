# xaas-castle-bridge-pack

Canonical ggen source for composing the XaaS outer Ash/Reactor control plane with the CASTLE BRCE consequence kernel.

## Manufacturing boundary

The pack owns static/reversible knowledge: supplier identity, public-ontology correspondence, edge topology, ERRC decisions, innovation compositions, SHACL and generated contract tests. It does **not** actuate providers.

The consumer keeps only irreducible runtime adapters handwritten. XaaS remains the outer admission/idempotency/receipt plane; CASTLE owns nested BRCE provider DO and content-addressed evidence. Exactly one bridge edge has consequential DO and it is `BRCE_ONLY`.

## ERRC

- **Eliminate:** duplicate Ash planes, ambient command authority, fictitious rollback of external consequences.
- **Reduce:** handwritten immutable contract/topology, public mutation routes, private semantic standing.
- **Raise:** exact supplier binding, nested receipts/replay, ggen-marketplace manufacture share.
- **Create:** reusable external-consequence composition, crash-recoverable receipt DAG, innovation composition profile.

## Consumer

XaaS vendors this pack's RDF facts and templates into its root ggen project because ggen correctly refuses output/path traversal outside the consumer root. `ggen sync` then manufactures the consumer-native Elixir contract, edge catalog, SHACL, ERRC reference, innovation manifest and contract test.
