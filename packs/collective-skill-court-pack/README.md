# collective-skill-court-pack

Reusable semantic manufacturing contract for converting provenance-bound procedural knowledge into bounded evaluation courts.

The pack does not grant execution authority. It binds three existing ecosystem surfaces:

- sJira `sjira:WorkOrder` for work identity, acceptance predicates, falsifiers, dependencies, and evidence ceilings;
- SA2A `sa2a:Candidate` for powerless semantic candidates and later MachineExperience compilation after independent admission/qualification;
- GymAct-compatible Oracle/NOP/mutation court semantics for bounded execution.

Admission is conjunctive: oracle passes AND no-op fails AND every declared known-wrong mutation is rejected AND `grants_do_authority == false`.

Generated output lives under `generated/` only when a consumer runs ggen. Generated output is not canonical pack source and is not committed here.
