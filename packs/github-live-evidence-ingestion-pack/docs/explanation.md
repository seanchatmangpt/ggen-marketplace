# Explanation: live evidence is not live authority

A GitHub response can be current without being authoritative for consequential action. This pack therefore treats capture, normalization, qualification, and actuation as separate morphisms. Capture is external observation; normalization is deterministic construction; qualification can refuse malformed or inexact subjects; none of those steps grants merge, deploy, release, or cloud authority.

The pack exists because the prior ControlOutcome pack had a precise missing edge: live captured evidence could not yet be converted into its deterministic exact-subject model. The new adapter closes that edge without coupling network access into generation. That separation keeps replay portable, makes raw input independently auditable, and allows multiple confidence or lineage algorithms to coexist over the same observation set.
