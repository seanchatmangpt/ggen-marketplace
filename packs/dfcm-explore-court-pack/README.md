# DfCM EXPLORE Court Pack

This pack preserves reversible candidate space as canonical RDF and manufactures a deterministic comparison matrix. Each candidate carries CTQ evidence, rollback cost, standing, and a named falsifier; executable SPARQL courts keep alternatives independently falsifiable.

Manufacture with the repository-qualified ggen runtime using this pack's `ggen.toml`. The generated `consumer/dfcm-explore/CANDIDATE_MATRIX.md` is a consequence, not an editing surface.

No candidate represented here has consequential execution authority. EXPLORE produces comparison evidence for downstream SELECT/DEVELOP; unknown authority must remain refused.
