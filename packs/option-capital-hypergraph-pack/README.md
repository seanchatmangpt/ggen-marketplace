# Option Capital Hypergraph Pack

Expands newly available capabilities into reversible composition candidates and deterministic opportunity-ledger projections while preserving SELECT / CONSTRUCT / DO separation.

## What it manufactures

- canonical capability → composition → candidate → repository → marketplace-support → missing-primitive → qualification → reversibility → expected-reuse → expected-capability-space-delta edges;
- a deterministic opportunity ledger ordered by capability-space delta, reuse, reversibility, then identity;
- a non-dominated reversible frontier projection;
- an explicit refusal gate for ambient DO authority.

## Composition seed

R22 composes the R21 manufacturing fanout controller with the existing capability-lineage and multicell-consumer factories. The pack itself performs no consequential actuation: `actuationPerformed=false` is part of the admitted ontology and generated projections.

## Qualification

Run the repository validation ladder from the root `AGENTS.md`, then exercise generation with the matching ggen runtime. `tests/test_contract.py` is a narrow structural and authority falsifier; it is not a substitute for consumer-boundary qualification.

## Reversibility

All candidates remain explicit ontology entities. A failed composition edge may be removed or marked dominated without collapsing adjacent candidates or granting actuation authority.
