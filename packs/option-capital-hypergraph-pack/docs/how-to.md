# How to extend the opportunity hypergraph

1. Add the capability as ontology source with an observed standing.
2. Add every lawful pairwise and bounded higher-order composition that remains reversible.
3. Add one candidate per executable composition and populate repository, marketplace support, missing primitive, qualification, reversibility, expected reuse, and expected capability-space delta.
4. Add an `oc:OpportunityEdge` binding those dimensions. Keep authority at SELECT and `actuationPerformed false`.
5. Regenerate ledger, frontier, and metrics. Compare repeated generation outputs byte-for-byte.
6. Run gates and consumer-boundary qualification before treating a candidate as ALIVE.

Do not collapse unrelated candidates when one edge fails. Record the failed edge as topology and preserve the remaining frontier.
