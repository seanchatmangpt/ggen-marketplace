# Adjacency Rebloom Controller Pack

Reusable ggen source for recursively expanding newly qualified capabilities into additional reversible composition candidates. It composes the live option-capital hypergraph, capability-lineage propagation, and manufacturing-fanout primitives while preserving SELECT != CONSTRUCT != DO.

## Standing

The pack manufactures frontier, plan, and receipt projections. It does not actuate external systems, merge repositories, deploy, release, or grant runtime authority. Every rebloom wave is bounded, receipt-required, deterministic by construction, and subject to fail-closed qualification.

## Qualification

Generate with the matching ggen runtime, compare two independent generation passes byte-for-byte, run `python3 gates/validate_rebloom.py generated/rebloom/plan.json`, then run `python3 -m unittest discover -s tests -p 'test_*.py'`. Consumer standing requires a separate exact-subject qualification boundary.
