# Tutorial: manufacture a rebloom wave

Start from qualified capability facts, not planner prose. Add reversible capabilities to `ontology.ttl`, run ggen, and inspect the projected frontier, bounded plan, and receipt. A valid wave preserves all non-dominated candidates, limits recursion depth/order, requires receipts, and remains CONSTRUCT-only. After a candidate is independently qualified, feed its resulting capability facts into the next observation epoch rather than granting this pack actuation authority.
