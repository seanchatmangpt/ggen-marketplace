# GreetCli

A tiny greet/math noun-verb CLI, generated by ggen (ex-noun-verb-cli-pack) from this Turtle ontology instance rather than hand-authored.

## Build

```
mix deps.get
mix escript.build
```

## Commands

- `./greet_cli greet hello`
- `./greet_cli greet shout`
- `./greet_cli math add`
- `./greet_cli math multiply`
