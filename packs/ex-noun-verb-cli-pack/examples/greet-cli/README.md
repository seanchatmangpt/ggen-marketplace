# GreetCli

A tiny greet/math noun-verb CLI, generated by ggen (ex-noun-verb-cli-pack) from this Turtle ontology instance rather than hand-authored.

## Build

```
mix deps.get
mix escript.build
```

## Commands

- `./greet_cli greet hello --name World`
- `./greet_cli greet shout --name World`
- `./greet_cli math add --x 2 --y 3`
- `./greet_cli math multiply --x 4 --y 5`
