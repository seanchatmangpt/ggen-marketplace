# Tutorial: measure realized replication capital

Start with an exact replication subject and its observed evidence. Materialize the facts as RDF using the pack ontology, including subject SHA, generation, standing, authority, receipts, falsifiers, evidence roots, consumers, qualification courts, and dependency-relief edges. Run the sensor corpus in numeric order. Treat returned rows as typed measurement opportunities, not authorization to mutate a consumer.

The reference fixture binds the R42 qualified replication surface to its exact head and current merged default evidence. The memory bootstrap record deliberately represents an empty canonical Project-memory namespace so memory continuity remains observable rather than assumed.

The first useful distinction is existence versus realization: a qualification court is an option-capital artifact; realized epistemic capital requires current subject identity, independent evidence, replay, and an observed downstream effect such as consumer reuse or dependency relief.
