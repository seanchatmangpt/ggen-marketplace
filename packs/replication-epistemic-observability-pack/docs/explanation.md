# Explanation: courts are not realized capital

R42 increased the ecosystem's reversible qualification option space by manufacturing fifty replication courts. R43 measures the next epistemic question: which of those options possess current exact subjects, independent evidence roots, downstream consumers, reproducible receipts, and realized dependency relief?

This avoids a common accounting error: counting an instrument as the phenomenon it measures. A court can be ALIVE as software while its target capability remains UNKNOWN or unrealized. Likewise a memory record can preserve a prior observation without remaining current. R43 therefore models current observations and remembered claims separately and makes disagreement observable.

The multiplier courts are deliberately fail-closed. Coverage, reuse, and opportunity fanout remain independent factors. Their product is only evidence for 1000X when each factor is grounded in the same admitted run and the explicit threshold sensor succeeds. Otherwise the shortfall is the result.
