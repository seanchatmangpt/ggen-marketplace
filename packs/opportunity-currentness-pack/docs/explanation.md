# Explanation

Default-branch movement is a topology change, not automatically a qualification failure. If a previously qualified exact head is contained by the newer default ancestry, its evidence remains valid for that subject while the default has advanced. This pack therefore separates CURRENT from CONTAINED_AFTER_DRIFT and reserves PARTIAL_ALIVE for unproven containment. Realization latency is likewise evidence about manufacturing flow, not authority to merge. Ledger refresh is append-only so later knowledge cannot erase the observation path that produced it.
