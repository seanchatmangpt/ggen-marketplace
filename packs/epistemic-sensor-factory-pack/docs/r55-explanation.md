# Explanation: why consumer merges are not producer-loop closure

A consumer can independently qualify and merge while the producer still lacks the returned receipt, deterministic projection surface, or dependency closure needed to manufacture the next consumer cheaply. R55 separates those facts.

The production function is therefore not `merged consumer -> standing propagation`. It is `exact consumer evidence -> bounded return capability -> reusable manufacture -> dependency closure -> new qualified consumer`. Standing and authority remain local to their evidence roots.

This distinction prevents event-count inflation from masquerading as 1000X leverage. The useful multiplier is the number of independently qualified consumers that the canonical producer substrate can reproduce and compose without bespoke reasoning.
