# R57 explanation: from throughput to production-function capital

R56 made higher-order consumer combinations observable. R57 asks the next question: which combinations actually increase future manufacturing capacity?

The distinction is structural. Commit count is an output measure; a production-function observation measures how one evidence-bearing capability changes three multiplicative dimensions: how much can be observed, how broadly a capability can be reused across exact subjects, and how many actionable downstream opportunities are created. A high number in one dimension cannot compensate for an unobserved dimension, a single evidence root, stale subjects, missing receipts, or no frontier expansion.

This turns 1000X into an admission problem. The reference 10×10×10 fixture proves only that the calculus and sensors execute. Live 1000X standing requires independently receipted live factor observations. The resulting machinery is reusable because future MEASURE cells can project the same evidence into a deterministic report and immediately identify the weakest multiplier rather than reconstructing the reasoning.
