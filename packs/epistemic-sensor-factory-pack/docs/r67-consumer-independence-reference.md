# Reference: R67 consumer-independence observability

R67 defines a ten-dimension evidence profile: repository, runtime family, language family, execution kernel, failure domain, authority domain, receipt protocol, qualification family, ontology profile, and hosting plane.

Courts 651–674 census identity/readiness substrate. Courts 675–685 condition diversity on admission or strong readiness. Courts 686–695 expose pairwise orthogonality and common-cause correlation. Courts 696–698 project readiness by major domains. Court 699 deterministically selects a non-admitted candidate; court 700 emits the clean exact-subject frontier.

The model reuses PROV-O, DQV, DCAT, DCTERMS and ODRL. `ADMITTED` is not synonymous with `ALIVE`: ALIVE requires observed execution against the exact admitted consumer subject. No R67 court carries consequential execution authority.
