# Explanation — why replication is epistemic capital

A producer-local sensor family increases observation depth but not portfolio reach. R46 separates **factory capability** from **consumer realization** and makes the latter an executable graph. That changes the production function: a future repository census can be transformed into exact target plans, qualification work, receipts, and typed gaps without rediscovering the rollout topology. The multiplicative factor is therefore measured as independently qualified consumers per reusable family, not inferred from source-code existence.
