# How-to — add a replication target

Add only observed exact-subject facts: repository URL, exact default-head SHA, eligibility observation, and an evidence root independent of the factory's own claim. Do not hand-edit generated replication plans. Regenerate, execute the R46 sensor tranche, qualify the consumer on its own repository boundary, and attach the resulting receipt. A target without its own execution remains `PARTIAL_ALIVE` or `UNKNOWN`, never inherited `ALIVE`.
