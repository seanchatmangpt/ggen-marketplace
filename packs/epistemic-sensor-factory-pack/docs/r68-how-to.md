# How to diagnose a stalled autonomic run

Run the R68 sensors against receipted run-control evidence. Start with orphan RUNNING, missing terminal time, missing post-actuation checkpoint, queue pressure, polling pressure, API failures, and exact-head churn. Follow the first observed broken transition rather than rerunning unchanged work. Convert each material failure into a typed opportunity, then repair the actual boundary. Do not treat a scheduler error string as a repository failure without graph evidence.
