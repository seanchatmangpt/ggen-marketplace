# Reference

`SensorFamilySpec` defines a reusable measurement family. `SensorSpec` defines one independently meaningful observable dimension. Required specification fields are family, metric, query pattern, and opportunity kind. The ggen rule `sensor-family-plan` deterministically projects admitted specifications to `generated/epistemic-sensor-factory/sensor-family-plan.json`. Authority is `OBSERVE|VERIFY|CONSTRUCT`; consequential actuation is prohibited outside BRCE.
