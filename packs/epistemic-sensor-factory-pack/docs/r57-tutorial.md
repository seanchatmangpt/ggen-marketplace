# R57 tutorial: measure the production function

R57 turns `1000X` into a falsifiable observation rather than a slogan. Start from exact subjects with receipts, populate one `esf:ProductionFunctionObservation`, then execute sensors 751–800. The three factors are observation coverage, portfolio reuse, and downstream actionable opportunity creation. A product is not admitted unless the factor evidence is independently rooted and the reachable frontier actually expands.

Use `fixtures/r57-production-function.ttl` as a reference-only example. Its 10×10×10 product demonstrates the calculus; it is not fleet evidence. Run `python3 packs/epistemic-sensor-factory-pack/tests/run_r57_production_function.py` to execute the permanent court.
