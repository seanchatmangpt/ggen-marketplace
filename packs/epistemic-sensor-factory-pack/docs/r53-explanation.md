# Explanation — why R53 changes the production function

Consumer admission, replication, and evidence return can increase breadth without proving that returned evidence actually creates new useful work. R53 makes that conversion measurable.

The key separation is:

`receipt happened before opportunity` != `receipt caused opportunity` != `opportunity relieved dependency`.

R53 therefore measures temporal order, causal witnesses, independent target roots, marginal opportunity yield, relief conversion, fanout, concentration, replay, and explicit multiplier shortfall. It preserves broad reversible opportunity discovery while refusing inherited standing or authority. This lets later cells allocate observation/manufacturing effort using realized causal yield rather than raw event volume.
