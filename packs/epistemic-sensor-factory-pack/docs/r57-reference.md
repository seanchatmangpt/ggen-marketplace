# R57 reference

Sensors 751–800 cover five layers: factor presence/value; factor evidence and root independence; frontier expansion; consumer/receipt/replay/relief evidence; and 1000X admission. `ProductionFunctionObservation` is a DQV quality measurement. Provenance and roots reuse PROV-O; portfolio resources reuse DCAT; descriptive identity reuses DCTERMS; authority remains ODRL read/derive with execute prohibited.

`multiplicativeProduct` must equal `observationFactor × reuseFactor × opportunityFactor`. Sensor 759 falsifies mismatch. Sensor 773 reports admitted products >=1000. Sensor 774 reports quantitative shortfall. Sensor 800 is the strict clean frontier and additionally requires each factor >=10, positive frontier delta, and at least two independent roots.

The generated `production-function-report.json` is a deterministic consequence of RDF/query/template state and is never an editing surface.
