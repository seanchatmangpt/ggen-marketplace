# Tutorial: Read the R57 consumer adapter frontier

R57 turns consumer replication gaps into executable selection evidence. Start from the canonical R55 grounded fixture, then execute `run_r57_consumer_adapter_capital.py`. The runner evaluates courts 751–800 against the public `ConsumerAdmissionCandidate` graph and refuses malformed or incomplete evidence.

The expected grounded state is four consumer families, two full adapter-ready consumers, and two consumers that still require receipt-return, deterministic manufacture, dependency closure, and generated-projection capability. The shortfall court reports eight consumers to the 10x fanout threshold; that number is evidence, not inherited standing.

Use the prioritized frontier court only to SELECT the next adapter candidate. It has no DO authority. Target-local manufacture and qualification must occur in the consumer repository, return an independent receipt, and be assimilated before consumer breadth changes.
