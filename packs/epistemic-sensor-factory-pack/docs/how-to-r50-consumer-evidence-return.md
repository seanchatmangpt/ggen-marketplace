# How to qualify a consumer evidence return

Use the R50 path when consumer execution evidence must become visible to producer-side measurement.

- Resolve consumer repository and HEAD to exact SHA.
- Resolve the canonical producer court to exact SHA.
- Execute the consumer court in VERIFY_ONLY mode and retain its machine-readable receipt.
- Record at least consumer head, producer court head, receipt digest, return source, independent evidence roots, replay result, and returned standing.
- Refuse assimilation when exact identity, replay, or evidence roots are insufficient for the claimed standing.
- Run the 350–399 sensor tranche and treat non-empty falsifier surfaces as typed EXPLORE work.
- A returned receipt may update observation/standing evidence. It may not grant SELECT, CONSTRUCT, or DO authority.

`ALIVE` requires observed execution on the exact consumer subject. A configured workflow without observed exact-head success remains `PARTIAL_ALIVE` or `UNKNOWN` according to available evidence.
