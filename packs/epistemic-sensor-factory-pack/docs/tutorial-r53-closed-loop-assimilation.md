# Tutorial: close the consumer evidence loop

R53 starts with an independently executed consumer receipt, not a producer-side readiness claim. The fixture binds the producer subject, the exact consumer qualification head, its merge commit, the containing default head, independent checks, and zero ambient DO.

Run the 50 sensors with `python3 packs/epistemic-sensor-factory-pack/tests/run_r53_sparql.py`. A qualified receipt may enter `ProducerAssimilation` only when replay, merge containment, evidence roots, and authority remain admissible. The resulting `ReplicationWave` is a reversible SELECT/CONSTRUCT projection; it does not actuate consumers.

Run ggen from the pack editing surface to render `closed-loop-assimilation-plan.json` and `next-wave-plan.json`. Treat those files as generated consequences, never hand-edit them.
