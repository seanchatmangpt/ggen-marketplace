2. Compare remembered Project-memory identities with live GitHub evidence; treat mismatches as stale observations.
3. Update the R58 evidence fixture or live projection source with exact subjects, independent evidence roots, receipts, standing, authority, ontology alignment, dependency closure, adapter need, and qualification path.
4. Run `python3 scripts/marketplace.py validate`.
5. Run `python3 packs/epistemic-sensor-factory-pack/tests/run_r58_consumer_factor.py`.
6. Deterministically regenerate the consumer-factor report with ggen and compare it with the admitted source graph.
7. Promote no consumer to ALIVE unless its exact subject has independently executed qualification evidence.
