# Reference: R68 run-closure evidence

Required run identity: `runId`, `subjectSha`, `cell`, `startedAt`, `state`, `authority`. Terminal runs additionally require `endedAt` and at least one bound receipt. Checkpoints have `checkpointKind`, `sequence`, and non-negative `latencySeconds`. Observable counters include meaningful commits, opportunities, merges, receipts, polls, head moves, API failures, and queue seconds. `actuationPerformed=true` is a falsifier for this OBSERVE|VERIFY measurement family. Sensor range: `2001`–`2050`.
