# Tutorial: return independent consumer evidence

This tutorial turns a consumer-side qualification into producer-observable epistemic capital without transferring execution authority.

1. Bind the consumer to an exact repository and exact commit SHA.
2. Execute the canonical producer-owned consumer court inside the consumer repository's VERIFY_ONLY authority boundary.
3. Preserve the resulting receipt with consumer head, producer court head, evidence-root identity, replay status, and zero consequential actuation.
4. Represent return as PROV-O evidence: `ConsumerReceiptAssertion -> EvidenceReturn -> ReturnedConsumerStanding`.
5. Assimilate only sufficiently grounded evidence into producer observation state; never infer consumer DO authority from the receipt.
6. Run sensors 350–399. Missing return, replay, evidence roots, exact identity, assimilation, or standing become typed opportunities rather than prose debt.

The reference fixture deliberately contains one independently ALIVE consumer and one PARTIAL_ALIVE consumer. The asymmetry is the teaching surface: workflow existence is not successful execution, and producer eligibility is not consumer standing.
