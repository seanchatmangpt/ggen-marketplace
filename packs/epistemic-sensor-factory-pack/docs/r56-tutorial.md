# Tutorial: from R55 consumers to an R56 composition frontier

Start with the R55 four-consumer fixture. Each candidate has an exact repository/head identity plus manufacturing properties such as receipt return, ggen manufacturability, dependency closure and replay.

Run the R56 court. The specimen has six unordered pairs and four unordered triples. Because all four consumers use distinct family labels, every pair and triple is cross-family. Only `ggen` and `chatgpt-cloud-elixir` jointly satisfy receipt-return, ggen-manufacturable, dependency-closed and projection-capable predicates, so the strict clean pair frontier contains exactly one combination.

That one row is not a deployment recommendation. It is an evidence-backed SELECT candidate for the next generation: construct a representation-neutral cross-consumer qualification experiment, preserve each consumer's authority ceiling, require independent exact-head receipts, and refuse any ambient DO.

The useful feedback loop is therefore `R55 unary readiness -> R56 combinatorial measurement -> selected cross-family experiment -> independent qualification -> new consumer evidence -> refreshed R55/R56 frontier`.
