# R58 explanation: why consumer factor is the bottleneck

Producer-side observation breadth can grow without increasing the production function if the same capability is not independently qualified and receipted across consumers. R58 therefore separates candidate fanout from independently ALIVE fanout. It measures exact-head currentness, evidence-root independence, replay, authority, public-ontology alignment, deterministic manufacture, qualification reuse, and returned standing before counting a consumer toward the multiplicative reuse factor.

This prevents a large producer-local sensor count from masquerading as ecosystem-wide 1000X evidence. R57 measures the multiplicative production function; R58 measures the presently weakest factor feeding it.
