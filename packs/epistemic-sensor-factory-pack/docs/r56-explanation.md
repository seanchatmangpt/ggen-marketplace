# Why R56 measures combinations

R55 answers whether individual consumers are independently ready for lawful manufacture. That unary view is necessary but insufficient for DfCM: a portfolio can contain individually healthy consumers while still having poor combinatorial breadth, shared qualification dependencies, adapter concentration, or weak cross-family composition.

R56 therefore treats consumer combinations as first-class observation subjects. Pair and triple sensors reveal whether manufacturing capital can span distinct consumer families while preserving exact-head identity, bounded authority, receipt return, deterministic ggen manufacture, dependency closure, replay, public ontology alignment, reusable qualification courts, and zero ambient DO.

This does not assert that composition is safe merely because each member is safe. R56 is a SELECT-side measurement surface. The clean frontier identifies combinations worth further falsification; a later CONSTRUCT/QUALIFY generation must prove actual correspondence for any selected composition.
