# Why R65 changes the measurement production function

R64 made realized manufacturing feedback observable. R65 closes the capital loop: observed outcomes become deterministic inputs to the next sensing portfolio. This replaces repeated manual sensor selection with an evidence-calibrated compiler while preserving DfCM breadth.

The compiler discounts stale, redundant, weak-root and low-relief sensing; raises complementary, replayable, exact-subject sensing; and exposes false-positive/false-negative allocation pressure. It does not collapse lawful alternatives and does not transfer authority. The phase change is recursive: each measurement run can now improve the machinery that chooses the next measurements.
