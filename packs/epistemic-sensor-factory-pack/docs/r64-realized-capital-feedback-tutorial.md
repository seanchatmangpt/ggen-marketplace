# Tutorial: close the allocation-to-realization loop

Start from a receipted production-function observation created after an R63 allocation. Measure `frontierBefore`, `frontierAfter`, and `frontierDelta`, then add downstream opportunity and reused-capability counts. Bind independent evidence roots, factor evidence, replay status, receipt, exact subject SHA, repository, and standing. Execute the R64 courts to separate positive but weakly evidenced gains from clean realized capital. Use the rankings only for SELECT; these observations never grant ambient DO authority.
