# Explanation: why evidence must return without authority

A replication compiler can select thousands of lawful consumer variants while still having weak realized replication if successful consumer execution remains trapped inside consumer-local CI. The missing production-function edge is not another producer sensor; it is a return channel that converts independent consumer execution into producer-observable evidence.

R50 separates four objects: the consumer subject, its qualification receipt, the return activity, and producer assimilation. This prevents two common category errors: treating producer eligibility as consumer ALIVE, and treating a consumer receipt as authorization for producer actuation.

The return loop is multiplicative because every consumer can contribute an independent evidence root to the portfolio. That raises replication observability and can generate new opportunities across compatibility, replay, falsifiers, dependency relief, and fanout. It does not by itself prove 1000X. The reference corpus has one independently ALIVE/replay-verified consumer against a desired factor of ten, so the observed consumer-factor shortfall is nine.

The architecture therefore preserves maximal consumer breadth while making realized evidence composable: select broadly, execute independently, return exact receipts, assimilate observationally, and keep BRCE as the exclusive consequential DO boundary.
