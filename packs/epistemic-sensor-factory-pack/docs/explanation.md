# Explanation: why the factory changes the production function

A sensor batch increases current observability; a sensor factory increases the rate at which future observability can be manufactured. The editing surface becomes semantic sensor specifications rather than bespoke query files. ggen projects those specifications into deterministic consequences, while qualification courts preserve exact-subject, evidence-root, replay, and authority constraints. The multiplicative target is therefore not more detectors per run, but more reusable detector families per admitted observation class.
