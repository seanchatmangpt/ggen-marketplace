# How to Generate from Strata ontologies

Every Strata pack is a generation contract: `ontology.ttl` is the semantic
source, `queries/` select, `templates/` project, `gates/` refuse invalid
inputs, and `generated/` holds consequences. This guide covers the one
recurring operation: regenerating a projection after an ontology edit.

## Prerequisites

- `ggen` on PATH.
- You are in the pack's directory (each pack is self-contained).

## Regenerate a projection

```bash
cd packs/strata-protocol-pack
ggen sync run
```

Repeat per pack; there is no family-level entry point. The command is
idempotent: the same ontology must produce byte-identical output. If re-running
changes the output, the pipeline is non-deterministic and that is a defect.

## After editing an ontology

1. Edit `ontology.ttl` — never the file in `generated/`.
2. Re-run `ggen sync run`.
3. Confirm the gates pass. Gates (`gates/*.rq`) are the admission step; a
   failing gate is a typed refusal that names the violated constraint. Repair
   the ontology, not the gate (unless the gate itself is wrong — then repair
   the gate with its own receipt).
4. Commit the ontology, template, and regenerated `generated/` files together
   as one dependency-closed change.

## Dependency order across the family

Generate in this order when several packs changed:

1. `strata-protocol-pack` — the wire kernel; others' wire vocabulary
   (`urn:strata:protocol:wire#`) agrees with it.
2. `strata-cas-pack`, `strata-pn64-pack`, `strata-signer-pack` — independent
   consumers of the wire/kernel vocabulary.
3. `strata-stratus-pack`, `strata-temprun-pack` — runtime-side vocabularies.
4. `strata-valve-pack` — the Elixir refusal taxonomy, which cross-checks the
   protocol pack's wire classes (32-byte `RefusalReceipt`).

The valve pack's gates literally query the protocol wire vocabulary, so if the
header or refusal-receipt contract changed, regenerate protocol first and let
the valve gates confirm agreement.

## Never hand-edit generated files

`generated/` output is a consequence, not a source. A hand edit:

- is silently destroyed by the next `ggen sync run`;
- breaks the idempotence check (regenerated bytes differ from committed bytes);
- splits truth between the ontology and a drift copy.

If the generated output is wrong, the fix is in the ontology (wrong value), the
query (wrong selection), or the template (wrong rendering). See
[../reference/strata-family-contracts.md](../reference/strata-family-contracts.md)
for the exact constants each projection must reproduce and
[../explanation/strata-family-design.md](../explanation/strata-family-design.md)
for the design rationale.
