# How to query the R15 option hypergraph

Load `packs/ggen-project-boundary-pack/option-hypergraph-amplifier.ttl` with one or more R15 fixtures into an RDF store, then execute the `r15-hyper-*.rq` files. Use census courts first, composition courts second, frontier/value courts third, and falsifier courts last. Treat query results as observation/verification evidence only. Do not convert rankings into consequential action without a separate admitted SELECT and BRCE-authorized DO path.
