# Crown Gap Hardening

The marketplace is the semantic supply plane. This branch hardens that role with machine-readable operator applicability and cross-repository identity contracts so downstream consumers do not duplicate capability or precondition facts.

Hard laws:

- semantic identity is canonical and provenance-bound;
- operator applicability is explicit data;
- generated projections do not grant DO authority;
- incomplete executable coverage is a refusal;
- all downstream projections are derived from admitted graph facts rather than hand-maintained parallel allowlists.
