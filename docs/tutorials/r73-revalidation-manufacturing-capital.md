# Tutorial: from stale memory to a qualified manufacturing plan

Start with a remembered repository head and independently observe the live head. If they differ, preserve the remembered record as provenance but mark the candidate for revalidation. Add the exact subject, evidence requirements, reversibility, authority cost and downstream capital estimates to the R73 graph.

Run the 51 courts. The stale-head courts explain why revalidation is required; the economic courts rank the non-conflicting portfolio; the falsifiers reject missing identity/evidence or ambient DO; and court 051 projects the admitted rows into a deterministic ggen plan.

The output is intentionally non-actuating. Feed each target into its owning exact-subject qualification path, return receipts, then update Y and M only from observed downstream manufacture.
