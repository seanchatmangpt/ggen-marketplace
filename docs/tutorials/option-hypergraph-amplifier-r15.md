# Tutorial: explore option-capital hypergraphs

Start from admitted capability observations rather than a preferred implementation. Represent reusable capabilities as vertices, compositions as hyperedges, and executable candidates as reversible projections. Use the R15 `r15-hyper-*` SPARQL courts to inspect pairwise and higher-order compositions, marketplace support, qualification surfaces, reuse, capability-space delta, authority cost, and falsifiers. Preserve non-dominated alternatives; a failed edge removes only that edge. Consequential DO is outside this tutorial and remains BRCE-only.
